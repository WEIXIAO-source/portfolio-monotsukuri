## 2. 色

| 役割 | 色（HEX） | 使う場所 | 根拠 |

| 主となる色（primary） |#795548 | 見出し、リンク、主なボタン |B 1印象を与え、菓子製造に合う落ち着いた色にするため |
| 補助の色（accent） |#D8A48F | 強調したい箇所（少量） |「温かい」印象を表現し、作品の魅力を引き立てるため。 |

| 文字（text） |#3E342F | 本文 |B 1「誠実・丁寧」な印象を保ち、文字を読みやすくするため。 |

## 6. CSS変数（AIに渡す部分）

1〜5で決めた値を書き込みます。AIには「この変数以外の色・サイズ・余白は使わない」と指示してください。

```css
:root {
  /* 色 */
  --color-primary: #795548;
  --color-accent: #D8A48F;
  --color-background: #FFF9F2;
  --color-surface: #FFFFFF;
  --color-text: #3E342F;
  --color-text-muted: #6B625D;
  --color-error: #B42318;
 /* 文字 */
  --font-heading: "Noto Serif JP", sans-serif;
  --font-body: "Noto Serif JP", sans-serif;
  --font-size-xl: 32px;
  --font-size-lg: 24px;
  --font-size-md: 16px;
  --font-size-sm: 14px;
  --font-size-xs: 12px;
  --line-height-body: 1.7;

  /* 余白 */
  --space-1: 8px;
  --space-2: 16px;
  --space-3: 24px;
  --space-4: 40px;
  --space-5: 64px;
  /* レイアウト */
  --content-max-width: 720px;
  --radius: 8px;
}
```
